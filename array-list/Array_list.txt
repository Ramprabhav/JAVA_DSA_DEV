# ArrayList in Java — Complete Notes

## 1. What is ArrayList?

`ArrayList` is a **resizable (dynamic) array** provided by Java's Collections Framework.

* **Array** → Fixed size
* **ArrayList** → Dynamic size; it can grow automatically when elements are added.

### Real-Life Example

Imagine a classroom:

* **Array:** There are 40 fixed chairs. Even if only 10 students come, the number of chairs remains 40.
* **ArrayList:** Chairs can be added or removed according to the number of students.

```java
ArrayList<Integer> list = new ArrayList<>();
```

---

## 2. Why Do We Need ArrayList?

### Array

```java
int arr[] = new int[5];
```

The size is fixed.

```text
[10, 20, 30, 40, 50]
```

You cannot directly increase the size of this array.

### ArrayList

```java
ArrayList<Integer> list = new ArrayList<>();
```

The size can grow automatically.

```java
list.add(10);
list.add(20);
list.add(30);
```

Output:

```text
[10, 20, 30]
```

# 5. Wrapper Classes

`ArrayList` stores **objects**, not primitive data types.

Therefore, we use **wrapper classes** for primitive types.

| Primitive Type | Wrapper Class |
| -------------- | ------------- |
| `int`          | `Integer`     |
| `char`         | `Character`   |
| `double`       | `Double`      |
| `float`        | `Float`       |
| `long`         | `Long`        |
| `boolean`      | `Boolean`     |
| `byte`         | `Byte`        |
| `short`        | `Short`       |

### Wrong

```java
ArrayList<int> list = new ArrayList<>();
```

### Correct

```java
ArrayList<Integer> list = new ArrayList<>();
```

Java automatically converts between primitives and their wrapper classes in many situations.

```java
int a = 10;

Integer b = a;    // Autoboxing

int c = b;        // Unboxing
```

# 6. Adding Elements

## `add(element)`

Adds an element at the end.

```java
list.add(10);
list.add(20);
list.add(30);
```

Output:

```text
[10, 20, 30]
```

---

## `add(index, element)`

Adds an element at a specific index.

```java
list.add(1, 100);
```

Before:

```text
[10, 20, 30]
```

After:

```text
[10, 100, 20, 30]
```

The existing elements are shifted to the right.

# 9. Updating an Element


After:


# 10. Removing Elements

## `remove(index)`

Removes the element at a particular index.

```java
list.remove(1);
```

Example:

```text
Before: [10, 50, 20]
After:  [10, 20]
```

---

## `remove(Object)`

Removes a specific value.

```java
list.remove(Integer.valueOf(20));
```

This removes the value `20`.

### Important Interview Point

For `ArrayList<Integer>`:

```java
list.remove(2);
```

means:

> Remove the element at **index 2**

While:

```java
list.remove(Integer.valueOf(2));
```

means:

> Remove the **value 2**

# 25. Nested ArrayList — 2D ArrayList

An ArrayList can contain other ArrayLists.

```java
ArrayList<ArrayList<Integer>> matrix = new ArrayList<>();
```

Create a row:

```java
ArrayList<Integer> row1 = new ArrayList<>();

row1.add(1);
row1.add(2);
```

Add the row:

```java
matrix.add(row1);
```

Print:

```java
System.out.println(matrix);
```

Output:

```text
[[1, 2]]
```

### Example of a 2D ArrayList

```java
ArrayList<ArrayList<Integer>> matrix = new ArrayList<>();

ArrayList<Integer> row1 = new ArrayList<>();
row1.add(1);
row1.add(2);

ArrayList<Integer> row2 = new ArrayList<>();
row2.add(3);
row2.add(4);

matrix.add(row1);
matrix.add(row2);

System.out.println(matrix);
```

Output:

```text
[[1, 2], [3, 4]]
```

# 26. Capacity vs Size

This is an important concept.

```java
ArrayList<Integer> list = new ArrayList<>(10);
```

Here:

```text
Initial Capacity = 10
Size = 0
```

After:

```java
list.add(5);
```

Now:

```text
Capacity >= 10
Size = 1
```

### Important

**Size** = Number of elements currently stored.

**Capacity** = Amount of internal storage available before resizing is required.

Capacity and size are **not the same thing**.

---

# 27. Internal Working of ArrayList

`ArrayList` internally uses an array.

Suppose the internal array needs more space.

When the current capacity is insufficient:

1. A larger internal array is created.
2. Existing elements are copied into the new array.
3. The new element is added.
4. The old array is discarded.

The exact growth policy is an implementation detail of the Java version, so don't rely on a fixed rule such as exactly `1.5x` for interview answers unless discussing a specific JDK implementation.

Conceptually:

```text
Small Array
     ↓
Resize
     ↓
Larger Array
     ↓
Copy Elements
     ↓
Add New Element
```

This resizing happens automatically.

# 28. Time Complexity

| Operation             | Time Complexity |
| --------------------- | --------------: |
| `get(index)`          |            O(1) |
| `set(index, value)`   |            O(1) |
| `add(element)`        |  O(1) amortized |
| `add(index, element)` |            O(n) |
| `remove(last)`        |            O(1) |
| `remove(index)`       |            O(n) |
| `contains()`          |            O(n) |
| `indexOf()`           |            O(n) |

### Why is `add(index)` O(n)?

Because elements may need to be shifted.

Example:

```text
Before:
[10, 20, 30, 40]

Insert 15 at index 1:

[10, 15, 20, 30, 40]
      ↑
Elements shifted →
```

# 29. Array vs ArrayList

| Array                                           | ArrayList                   |
| ----------------------------------------------- | --------------------------- |
| Fixed size                                      | Dynamic size                |
| Can store primitives and objects                | Stores objects              |
| Uses `length`                                   | Uses `size()`               |
| Fewer built-in operations                       | Many useful methods         |
| Can be more memory-efficient for primitive data | Has object/wrapper overhead |
| Size cannot be changed directly                 | Automatically resizes       |
